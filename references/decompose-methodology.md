# 单视频逆向拆解 + 全账号内容增长总结 方法论

把抖音博主视频拆成"内容结构、流量机制、用户心理、可复制方法论"，再聚合出账号的长期内容规律与增长模型。

**数据前提（逐条视频都要有）**：① 标题/文案 ② 时长 ③ 发布时间 ④ 互动(赞/评/藏/享) ⑤ 完整口播稿/字幕 ⑥ 每秒画面帧 ⑦ BGM/音频 ⑧ 评论区 ⑨ 博主基础信息。
原则：结论没有直接证据就标「推测」，不虚构；评论区是"内容假设的用户验证"，评论数量不直接等于观点代表性。

## Prompt 1｜单条视频深度拆解（11 节）

角色：抖音内容策略师 / 短视频编导 / 用户心理分析师 / 商业化内容研究员。

### 一、视频定位
输出：内容主题 / 内容赛道 / 视频类型(`知识|测评|种草|剧情|经验|教程|观点|情绪|Vlog|案例|避坑|对比|清单|故事|带货|其他`) / 目标人群 / 核心场景 / 用户核心痛点·需求 / 核心价值 / 核心情绪 / 一句话内容概括。

### 二、前 3 秒 Hook
分析：第一帧 / 第一段口播 / 第一屏文字 / Hook 类型 / 钩哪类人 / 利用什么痛点·欲望·好奇 / 为何继续看。
抽象为可迁移结构，不复制原话：> **Hook公式：______**

### 三、内容结构（结合口播稿 + 每秒帧）
表格：时间段 | 口播核心内容 | 画面内容 | 这一段作用。
作用枚举：`钩子 / 建立场景 / 提出问题 / 放大痛点 / 制造好奇 / 提供观点 / 给解决方案 / 案例证明 / 产品展示 / 情绪推动 / 反转 / 总结 / CTA`。
抽象：> **Hook → ______ → ______ → ______ → CTA**

### 四、口播文案拆解
语言风格：开头方式 / 信息密度 / 句子长短 / 口语化 / 用数字 / 反问 / 制造冲突 / 制造信息差 / 具体案例 / 不断设"小钩子" / 金句 / CTA方式。
提取：核心观点 > 核心利益点 > 最强的一句话 > 文案底层公式。

### 五、画面拆解（结合每秒帧）
第一帧视觉钩子 / 主体人物·产品 / 拍摄场景 / 景别变化 / 镜头切换频率 / 字幕形式 / 重点文字 / 产品出现节点 / 视觉证明 / 情绪画面 / 前后对比 / 重复视觉元素。
找：哪些画面**留人** / **解释** / **证明** / **制造情绪**。> **视觉结构公式：______**

### 六、BGM 与节奏
BGM类型 / 情绪 / 是否热门音乐 / 与内容匹配度 / 节奏快慢 / 音乐高潮是否对应关键内容 / 主要承担(情绪|节奏|熟悉感|热点借势|氛围|其他)。
> 若替换 BGM，最需保留的情绪是？

### 七、用户心理链路
刷到 → 停留 → 继续看 → 产生兴趣 → 产生认同 → 觉得"有用/想要" → 评论/收藏/分享 → 关注 的心理动线。
> 这条视频真正击中的用户心理是：______

### 八、评论区分析
把评论分类：`认同型 / 需求型 / 提问型 / 购买意向型 / 反对质疑型 / 补充讨论型 / 情绪共鸣型 / 玩梗型 / @好友分享型`。
输出：高频关键词 / 最关注问题 / 真正需求 / 最大疑虑 / 视频未满足的需求 / 反向下一条视频的选题。
> 评论区是对内容假设的用户验证，勿把数量当代表性。

### 九、内容表现原因
结合互动数据，分别判断"为什么可能获得 播放/点赞/评论/收藏/分享/关注"。无对照数据用「可能原因」而非「确定原因」。

### 十、单视频最终提炼
核心选题 / 核心Hook / 核心用户需求 / 核心内容结构 / 核心情绪 / 核心画面策略 / 核心评论反馈 / 最值得复用 3 元素 / 可测试变量。
> **______ + ______ + ______ + ______ = 这条视频的内容模型**（一句话内容公式）
> **真正有效的不是「____」，而是「____」**

### 十一、标准化标签（供全量聚合，必须字段）
```text
内容赛道： 内容类型： 目标人群： 核心选题：
一级痛点： 一级欲望： Hook类型： Hook公式：
内容结构： 核心情绪： 核心卖点/价值： 证明方式：
画面类型： BGM情绪： CTA类型： 评论核心需求：
评论核心疑虑： 可衍生选题：
```

## Prompt 2｜博主全量视频总结（11 节）

角色：账号策略师 / 内容增长分析师 / 短视频创意研究员。全部视频统一格式拆解结果 + 账号主页数据在手。

区分：**高频共性 / 爆款特有 / 普通视频特征 / 偶然现象 / 稳定规律**。有互动数据优先做"高表现 VS 普通"对比，不只研究爆款。

### 一、账号定位
赛道 / 核心目标人群 / 核心内容价值 / 核心用户需求 / 核心人设 / 核心专业标签 / 核心情绪价值 / 用户为什么关注 / 与同类最明显差异。
> 帮助【谁】，通过【什么内容方式】，解决【什么问题/满足什么需求】
### 二、选题地图
一级内容支柱 / 二级主题 / 高频·低频选题 / 爆款·高收藏·高评论·高分享选题。树状输出，并回答：反复解决的 3~5 个用户问题。
### 三、Hook 规律
最常用 Hook / 爆款最常见 Hook / 普通最常见 Hook / 第一帧规律 / 第一屏文字规律 / 第一段口播规律。Top 5 Hook公式（只提炼结构）。
### 四、内容结构规律
最常见结构 / 爆款结构 / 高收藏结构 / 高评论结构 / 高关注结构。提炼核心内容模板 3~5 种。
### 五、画面规律
常见场景 / 景别 / 人物出镜方式 / 产品出现方式 / 字幕风格 / 转场频率 / B-roll / 第一帧规律 / 视觉证明 / BGM规律 / 时长规律。
区分：**稳定视觉资产** vs **可测试视觉变量**。
### 六、用户需求地图（结合全部评论）
高频痛点 Top10 / 高频需求 Top10 / 高频问题 Top10 / 高频购买顾虑 Top10 / 高频情绪 Top5 / 常被@朋友的视频类型 / 常被收藏的视频类型。建立用户画像→场景→问题→情绪→需求→期望结果 链路。
### 七、爆款 VS 普通视频（有数据时）
划分头部/中位/尾部，对比：选题 | Hook | 前3秒 | 时长 | 内容结构 | 情绪 | 画面 | BGM | CTA | 评论需求。只把"反复出现"的差异当规律。
### 八、账号内容公式
选题公式 / Hook公式 / 内容结构公式 / 画面公式 / 情绪公式 / 用户增长公式 / 爆款公式。
### 九、博主内容 DNA
最擅长讲什么 / 对什么人讲 / 用什么方式讲 / 用户为什么信 / 为什么持续关注 / 换掉哪些元素就不像他了。
> 不可替代的内容 DNA：______
### 十、机会挖掘
已验证方向 / 反复验证可深挖方向 / 评论有需求但未覆盖方向 / 已明显同质化方向 / 值得测试的新方向。
### 十一、最终输出
博主 5 大内容支柱 / Top5 Hook 公式 / Top5 内容结构 / Top10 用户需求 / 最值得复制的 5 个底层机制 / 最值得测试的 5 个新变量。
> **【目标人群】+【核心痛点/欲望】+【Hook方式】+【内容价值】+【表达形式】+【情绪价值】= 核心内容模型**
> **表面上在做「____」，长期在向用户提供「____」**

## 技能落地（分析执行要求）

1. **全量标准化标签**：对每一条视频跑 Prompt1 的第 11 节字段，产出逐条 18 字段标签，汇总成 `<account>/decompose/tags.json`（供账号聚合，勿逐条手写进长文）。
2. **代表深度拆解**：对爆款 TOP10 + 典型（高收藏/高评论/高分享/带货模板类）逐条输出 Prompt1 全套 11 节（配真实抽帧）。
3. **账号级总结**：全部标签 + 账号主页数据 → Prompt2 全 11 节。
4. **评论数据来源**：`tools/comments.py` 从评论 jsonl 提取每视频评论文本/楼中楼聚合；无评论的视频在评论维度标「缺源」。
5. 报告引用任何组间数字（如 BGM×互动）取 `_cross.json` / `tags.json`，勿手写。
