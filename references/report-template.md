## 章节骨架（01–07）

### 01 如何把达人列为对标账号

> 固定讲「怎么选 + 怎么做」，不分析达人本人。

- `### 1.1 什么是对标账号`：定义一段；`#### ① 赛道匹配 / ② 量级可参照`，每项下 `-` 列 3 条判定标准。
- `### 1.2 建立对标的五步法`：编号 1–5 步骤卡（全量数据采集 → 口播逐字稿化 → 画像与内容拆解 → 变现路径拆解 → 持续追踪迭代），每步一段讲"产出什么"。
- 结尾 `>` 收治区：说明「第 5 步（持续追踪）需后续定期执行，工具已就绪」。

### 02 达人画像总览

- 章首 4 大数字（作品总数 / 累计获赞 / 平均单条点赞 / 评论率）。
- `### 2.1 账号基本盘`：表格 `| 维度 | 数据 | 解读 |`，至少含昵称/作品总量/活跃周期/年发布量/平均互动/点赞分布。
- `### 2.2 互动特征：{关键特征}`：分析段 + `>` 数据口径提示（可见样本可能被筛选，数值是上界）+ 结论条 + `关键启示`。
- `### 2.3 发布规律`：时段/星期分布 + 图注（`图 1 · 发布时段分布（按小时）` + `数据来源：...`）+ `关键启示`（指出可抢占空白时段）。

### 03 内容矩阵拆解

- `### 3.1 内容主题结构`：表格 `| 内容主题 | 条数 | 占比 | 平均赞 | 平均评 | 平均藏 | 定位 |`，末尾「其他/未分类」行并给合计。
- `### 3.2 爆款公式`：`①~⑤` 编号列出爆款共同特征（开场口号/场景/情绪文案/互动钩子/BGM）。
- `### 3.3 爆款 TOP10 特征`：表格 `| 点赞 | 收藏 | 评论 | 分享 | 日期 | 标题特征 |`。
- 收尾 `关键洞察`：指出"哪类负责涨粉、哪类才是真正能爆的带货内容"。

### 04 文案写作逻辑深度拆解

> 全文最重的一章，按固定顺序展开 7 节。

- `### 4.1 总框架`：给「总公式：【】＋【】＋【】」一行 + 示例；随后 `#` 放 3–4 个关键统计（感叹号数/称呼锚点/固定开场/标签次数）；`为什么"重复"反而有效` 用 ①②③ 讲机理。
- `### 4.2 固定口号系统`：每个口号 `# 口号` + 一句解释 + 一句作用；再拆到句法层讲「打招呼/定场景/发邀请」。
- `### 4.3 标题三段式`：公式 + 「变量槽可选项」列表（来自真实数据）+ `样本①/②/③` 逐条高赞标题拆解。
- `### 4.4 "金句切片"`：表格 `| 话术线 | 示例（原文） | 写作手法 |`（如人生励志/早安陪伴/处世心境/幽默自嘲）+ `关键洞察`。
- `### 4.5 口播的"语料地图"`：先做「诚实校正」（多少条无旁白/多少条是歌词），再列真正口播集中于哪几类；`为什么标题感叹号多而口播少`。
- `### 4.6 带货口播`：给**一条 N 段式卖货模板**（① 命名/诗句定调 → ② 身份背书 → ③ 溯源/工艺 → ④ 五感 → ⑤ 量化价值 → ⑥ 场景喝法 → ⑦ 直播预告收尾）+ 按单品拆段落对比表 + `{战略名}` 收治区（讲多单品共用统一场景记忆点）。
- `### 4.7 CTA 与评论区互动钩子`：统计「行动指令词频」（关注>不见不散>直播间>点赞>评论区），编号 1/2/3 列互动钩子，末尾 `可照抄的动作清单`。

### 05 带货与变现逻辑

- `### 5.1 产品叙事 N 步模板`：`①~⑤` 编号（诗句/文化开场 → 产地背书 → 口感/功效具象化 → 场景建议 → 直播预告），每步配一句真实例证。
- 后续小节可扩展：单品策略 / 客单与定价叙事 / 直播引流闭环 / 评论区成交运营。

### 06 直播逻辑拆解

- 直播频次/时长/场观；`###` 直播话术结构（开场互动 → 讲品（复用 04.6 分段模板）→ 促单限定 → 抽奖/宠粉收尾）。
- 强调「视频种草 → 固定时段直播承接 → 买赠抽奖促单」引流闭环；`. 逐字稿口径说明`（原始版 + 校对版）。
- **无直播数据时**：`数据口径提示` 声明缺源 +「推断型结论」标注，不得伪造逐字稿。

### 07 差异化 · 起号方案

- 起手列举对标账号**结构性弱点**（对应 03 主题缺口 / 同质化 / 更新频率 / 时段空白）。
- 分维度给方案：选题层（缺口补位 + 节日日历）/ 结构层（开头 2 秒钩子 + 时长 + CTA 收敛）/ 运营层（四维命中判定 + 对标池 3–5 个）/ 合规层（禁用词 + 证据链 + 促销口径）。
- 每节用 `可照抄的动作清单` 或结构化列表收口。

## 版式与写作规范（贯穿全文）

1. **文档头**：`由 TraeWork 生成` 固定；主标题 `# 抖音{品类}达人对标分析报告`。
2. **大数字**：章首 4 连发用 `# N`（居中、带单位说明）；数据样本卡用 `## N *单位*`。
3. **序号**：流程/步骤用 `① ② ③ ④ ⑤ ⑥ ⑦`；编号卡用 `1` `2` `3`；子项层级 `####`。
4. **表格**：信息密度表统一 `| 维度 | 数据 | 解读 |` 或 `| 主题 | 条数 | 占比 | 平均值×N | 定位 |`。
5. **收治区 / callout**：统一用五类 `关键启示 / 关键洞察 / 数据口径提示 / 为什么"重复"反而有效 / 可照抄的动作清单`，全用 `>` 引用块呈现，首行是标题。
6. **加粗**：关键标签与结论首词 `**加粗**`；达人原话用引号「」。
7. **诚实口径**：凡口径可能被筛选（可见样本/上界）或存疑，必须用 `数据口径提示` 显式声明，不得虚构缺失的源/数据/截图。
8. **结尾附言**：数据来源、采集工具、局限声明、合规边界，字号较小。
9. **HTML 渲染时**：图片用真实抽帧/封面，禁用 AI 生成图；TOP 素材拆解配真实抽帧条。

- 各 `{占位}` 用该次抓取的**全量真实数据**替换；硬编码数字（总数/均值/分类条数/爆款榜/时间范围）必须与最新数据集一致，不得沿用旧样本。
