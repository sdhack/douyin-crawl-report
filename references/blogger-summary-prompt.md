# 博主全量视频总结 · 账号级深度总结提示词（MANDATORY）

> 用途：当用户要求"博主全量视频总结 / 账号级内容增长总结 / 内容DNA"时，对 `decompose/<account>/video_profiles.{json,md}` + `decompose/<account>/tags.json` + `video-analysis/<account>/comments.json`（全量视频的统一拆解结果 + 账号主页数据）+ `decompose/<account>/_metrics.json`（由 `tools/account_metrics.py` 自动产出：**发布节奏 / 互动交叉聚类 / 话题策略 / 高赞评论**，为必吃数据）执行本提示词，产出**账号级总结内容**；随后用技能内建 `render_report.py --stdin` 一步渲染为自包含单文件 HTML（不落 .md）。
> 与 `decompose-methodology.md` 的关系：那是"逐视频拆解"的方法论与数据链；本文是"账号维度汇总那几个规律"的标准分析提示词 + 输出骨架。

## 分析提示词（逐条遵循）

> 这 11 节的定性要求：分析时必须区分 高频共性 / 爆款特有特征 / 普通视频特征 / 偶然现象 / 稳定规律；有互动数据时优先做「高表现 VS 普通」对比，不只研究爆款。

1. **账号定位**：赛道 / 核心目标人群 / 核心内容价值 / 核心用户需求 / 核心人设 / 核心专业标签 / 核心情绪价值 / 用户为什么关注他 / 与同类最明显差异 → 一句话定位：「这是一个帮助【什么人】，通过【什么内容方式】，解决【什么问题/满足什么需求】的账号。」
2. **选题地图**：统计全部选题，归类 一级内容支柱 / 二级主题 / 高频选题 / 低频选题 / 爆款选题 / 高收藏选题 / 高评论选题 / 高分享选题；输出 `内容支柱A ⇢ 选题1/2/3` 树；判断博主真正反复解决的 3–5 个用户问题。**必读 `_metrics.json` 的「发布节奏」**：首末条/跨度/月均/峰值月份/间隔中位/断更，判断更新频率与经营投入，及发布节奏与互动的关系（是否爆款聚集在特定节奏）。
3. **Hook 规律**：全部视频最常用 Hook 类型、爆款最常见、普通最常见；第一帧规律、第一屏文字规律、第一段口播规律 → 提炼 **Top 5 Hook 公式**（只提炼结构，不复制具体文案）。
4. **内容结构规律**：统计最常用叙事结构（痛点→观点→案例→解决→总结 之类），找 最常见 / 爆款常见 / 高收藏 / 高评论 / 高关注 结构 → 提炼博主核心内容模板 3–5 种。
5. **画面规律**：全视频常见的 拍摄场景/景别/人物出镜/产品出现/字幕风格/转场频率/B-roll/第一帧/视觉证明/BGM/时长 → 区分「稳定视觉资产」与「可测试视觉变量」。
6. **用户需求地图**（结合评论区，不只看博主表达）：高频痛点 Top10 / 高频需求 Top10 / 高频问题 Top10 / 高频购买顾虑 Top10 / 高频情绪 Top5 / 常@朋友的视频类型 / 常收藏的视频类型 → 建立 人群→场景→问题→情绪→需求→结果 链路。**必读 `_metrics.json` 的「话题策略 + 高赞评论Top20」**：用 hashtag 词频+均赞判断涨粉话题 vs 引流话题，用高赞评论原文+所属视频归纳用户真实需求"，不编造需求。
7. **爆款 VS 普通**：有数据则把视频分 头部/中位/尾部，逐变量对比（选题/Hook/前3秒/时长/内容结构/情绪/画面/BGM/CTA/评论需求）；只把**反复出现**的差异判为规律。**必读 `_metrics.json` 的「互动交叉聚类」**：结合整体互动结构（收藏/评论/分享率中位、最高赞单条占比）与 爆款型/收藏型/讨论型/分享转执型 Top5，识别账号内容分型规律（收藏型=干货/教程、讨论型=话题争议、分享转执型=转念/社交货币）。
8. **账号内容公式**：提炼 选题公式 / Hook公式 / 内容结构公式 / 画面公式 / 情绪公式 / 用户增长公式 / 爆款公式。
9. **博主内容 DNA**：他最擅长讲什么 / 对什么人讲 / 用什么方式讲 / 用户为什么信他 / 为什么愿意持续关注 / 哪些元素换掉账号就"不像他" → 一句话：账号真正不可替代的内容 DNA。
10. **机会挖掘**：已验证方向 / 可继续深挖方向 / 评论区有需求但未覆盖方向 / 已同质化方向 / 值得测试的新方向。
11. **最终输出**：浓缩 博主5大内容支柱、Top5 Hook公式、Top5 内容结构、Top10 用户需求、最值得复制5个底层机制、最值得测试5个新变量 → 一句话账号模型 =【目标人群】+【核心痛点/欲望】+【Hook】+【内容价值】+【表达形式】+【情绪价值】 → 最终一句话：表面上在做「」，实际上长期提供「」。

## 渲染

把按上述骨架写好的 MD 交给 `tools/render_report.py` 渲染为自包含单文件 HTML：

```
python tools/render_report.py --source 博主全量视频总结.md [--key "CREATOR SUMMARY"] --inline [--design '<json>']
```

> 三大约束（硬性）：**默认单栏无目录**（`--no-toc` 即缺省，别加 `--toc`）；**图片自动相册网格两两成排、限高 460px 不突兀**；**骨架全局恒定**、只经 `--design '<json>'` 换设计美学，不手动改骨架。
>
> 渲染器会对：`## N 开头` 且非章节序号 → 数据样本大数字卡；`## 01/一、` 章节 → 主章节；`> 关键洞察/数据口径提示` → 收治区配色；嵌套 `- ` 列表 → 层级树；`|` 表格 → 细线表。开篇大数字/样本卡用 `## {N} *条*` 形式即可自动变卡。
